# Procesamiento de Datos a Gran Escala - Taller 1 de Python

## Descripción

Este repositorio contiene el desarrollo del Taller 1 de la asignatura **Procesamiento de Datos a Gran Escala**. El objetivo principal del taller es fortalecer las habilidades de programación mediante la resolución de ejercicios prácticos y la documentación adecuada de cada una de las actividades desarrolladas.

A lo largo de los diferentes cuadernos, se abordan los conceptos fundamentales del lenguaje Python mediante ejemplos prácticos, ejercicios guiados y cuestionarios diseñados para reforzar el aprendizaje. Cada actividad incluye una explicación del procedimiento implementado y la evidencia de la correcta ejecución del código.

## Contenido del repositorio

El repositorio está organizado en nueve cuadernos, cada uno enfocado en un tema específico del lenguaje Python:

### 1. Cadenas

En este cuaderno se estudian los fundamentos del manejo de cadenas de texto, incluyendo el acceso a los caracteres mediante índices, la indexación negativa, el uso de *slicing*, los recorridos mediante *stride*, la concatenación y diferentes técnicas para la manipulación de texto.

### 2. Tuplas

En este cuaderno se desarrollan ejercicios relacionados con la creación y el manejo de tuplas. Se estudian conceptos como la indexación, la concatenación, la extracción de subconjuntos mediante *slicing* y el uso de tuplas anidadas para representar estructuras de información más complejas.

### 3. Listas

En este cuaderno se trabajan diferentes operaciones relacionadas con las listas, una de las estructuras de datos más utilizadas en Python. Se estudian temas como la indexación, el almacenamiento de diferentes tipos de datos, la manipulación de elementos, la clonación de listas y la aplicación práctica de los conceptos mediante ejercicios integradores.

### 4. Conjuntos

En este cuaderno se desarrollan ejercicios relacionados con la creación y el manejo de conjuntos. Se analizan las operaciones entre conjuntos, las operaciones lógicas y las diferentes herramientas disponibles para comparar y organizar grupos de datos.

### 5. Diccionarios

En este cuaderno se estudian los diccionarios como estructuras de datos basadas en pares de clave y valor. Se desarrollan actividades relacionadas con la creación, consulta, modificación y administración de la información almacenada mediante el uso de llaves.

### 6. Condiciones

En este cuaderno se abordan los operadores de comparación, los operadores lógicos y las estructuras condicionales. Las actividades permiten comprender cómo implementar procesos de toma de decisiones mediante el uso de las sentencias `if`, `elif` y `else`.

### 7. Bucles

En este cuaderno se estudian las estructuras repetitivas utilizadas para automatizar tareas. Se desarrollan ejercicios relacionados con la función `range()`, el ciclo `for` y el ciclo `while`, aplicando diferentes estrategias para recorrer y procesar información.

### 8. Funciones

En este cuaderno se trabaja la creación y el uso de funciones en Python. Se estudian las funciones predefinidas, la definición de funciones personalizadas, las estructuras condicionales dentro de las funciones, los argumentos predeterminados y el alcance de las variables.

### 9. Clases

En este cuaderno se introducen los fundamentos de la programación orientada a objetos. Se desarrollan ejercicios relacionados con la creación de clases, la definición de atributos y métodos, la creación de objetos y la representación gráfica de información mediante el uso de Matplotlib.

## Herramientas utilizadas

* Python.
* Databricks.
* Matplotlib.

## Organización del repositorio

Cada cuaderno se encuentra organizado en secciones temáticas que incluyen explicaciones teóricas, ejemplos prácticos, ejercicios de aplicación y cuestionarios para reforzar los conocimientos adquiridos. La documentación incorporada en cada archivo permite comprender el procedimiento seguido durante el desarrollo de las actividades.

## Conclusión

El desarrollo de este taller permitió fortalecer los conocimientos fundamentales del lenguaje Python mediante la implementación de diferentes estructuras de datos, algoritmos y herramientas de programación. Asimismo, la documentación de cada actividad contribuyó a mejorar la organización del código y la comprensión de los diferentes conceptos estudiados, proporcionando una base sólida para futuros proyectos relacionados con el procesamiento de datos a gran escala.
